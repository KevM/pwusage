The trimmed rate fixtures come from Daniel Zimny-Schmitt and Jay Huggins/NREL,
[Utility Rate Database](https://data.openei.org/submissions/5), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Export keys were
normalized to API names and only fixture fields retained.

The utility directory is derived separately from OpenEI's EIA Utility Companies
and Aliases category.
